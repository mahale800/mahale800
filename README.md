# Yash Mahale

Developer portfolio for frontend, AI, and security-lab projects.

## Featured projects

- [Sharma Store](https://github.com/mahale800/sharma-store) — a mobile-first React storefront prototype with Firebase, PWA features, loyalty flows, and admin screens.
- [React Performance Optimization Playground](https://github.com/mahale800/react-performance-optimization-playground) — focused examples of common React performance problems and practical optimizations.
- [CYPHER Study Assistant](https://github.com/mahale800/study-bot-ai-assistant) — a FastAPI and Groq-powered study assistant with MongoDB-backed threads and a WebGL frontend.
- [Clash of Teams 101](https://github.com/mahale800/clash-of-teams-101) — an isolated Docker lab for practicing reconnaissance, traffic analysis, and remediation workflows.
- [Portfolio — Tailwind CSS](https://github.com/mahale800/portfolio-TailwindCss) — a small responsive portfolio page built with HTML, Tailwind CSS, and AOS.

## Focus areas

- React, Vite, and responsive frontend interfaces
- Python APIs and AI-assisted applications
- Firebase, MongoDB, and browser-based persistence
- Containerized cybersecurity learning labs

Each repository README includes its current status, setup steps, limitations, and validation notes. These projects are portfolio and learning work; review the individual project documentation before using any of them in a production environment.
